## 🛠️ Tecnologias Utilizadas
Este site foi construído do zero, focando em um design moderno (Dark Mode), responsivo e de alta performance.
* **HTML5:** Estruturação do conteúdo.
* **CSS3:** Estilização, animações e design responsivo (Flexbox e Grid).
* **JavaScript:** Lógica de navegação entre as páginas (Single Page Application) e efeitos de zoom nas imagens.
* **FontAwesome:** Biblioteca de ícones.
* **Google Drive API:** Hospedagem do currículo em PDF para download.
